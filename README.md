# Course: C++ Programming — Capstone Project "Library"

Welcome to the main repository of the course. This repository contains all
the lessons of the capstone project **Library**, a console-based library
management application written in C++.

## Course objective

Learn C++ programming through a concrete project, built progressively
lesson by lesson. Each lesson adds a feature to the program and introduces
the concepts required to implement it.

## Repository structure

## Download a lesson

Each lesson has its own GitHub repository, so you can download only the
code for the lesson you are currently working on:

| Lesson | Repository | Content |
|---|---|---|
| 01 | [lesson-01-intro](https://github.com/amoungui/lesson-01-intro) | First C++ program: welcome message |
| 02 | [lesson-02](https://github.com/amoungui/lesson-02) | Library welcome message simulation |
| 03 | *coming soon* | *coming soon* |

To get the code of a lesson:

- **With Git**: `git clone https://github.com/amoungui/lesson-0X.git`
- **Without Git**: click the green **Code** button → **Download ZIP**

## Build a lesson

Each lesson folder contains a Visual Studio solution (`.slnx`).
Open it in Visual Studio, then build with `Ctrl+Shift+B`.

## Requirements

- Visual Studio 2022 (or later) with the "Desktop development with C++"
  workload
- Git (optional, for cloning the repositories)
