# Lesson 01 — Introduction to C

First lesson of the capstone project **Library**. This program prints a
welcome message to the console.

## Learning objectives

- Create a C++ project in Visual Studio
- Understand the structure of a C++ program (`main`, `#include`, `std::cout`)
- Build and run a program
- First contact with Git version control

## Contents

| File | Purpose |
|---|---|
| `library.cpp` | Program source code |
| `library.slnx` | Visual Studio solution |
| `library.vcxproj` | Visual Studio project |
| `library.vcxproj.filters` | File organization in the IDE |
| `.gitignore` | Files excluded from version control |

## Build and run

1. Clone the repository or download the ZIP:
   ```bash
   git clone https://github.com/amoungui/lesson-01.git

2. Open library.slnx in Visual Studio.

3. Build with Ctrl+Shift+B.

4. Run with F5 (or Ctrl+F5 to run without debugging).

## Expected output
Welcome to the library management application.
