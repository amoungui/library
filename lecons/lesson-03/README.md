# Lesson 02 — Welcome message simulation

Second lesson of the capstone project **Library**. The program simulates
the welcome message of a library management application.

## Learning objectives

- Use variables and constants
- Work with strings (`std::string`)
- Print a formatted message to the console
- Organize a program into simple functions

## Contents

| File | Purpose |
|---|---|
| `library.cpp` | Program source code |
| `library.slnx` | Visual Studio solution |
| `library.vcxproj` | Visual Studio project |
| `library.vcxproj.filters` | File organization in the IDE |
| `.gitignore` | Files excluded from version control |

## Build and run

1. Clone the repository or download the ZIP:
   ```bash
   git clone https://github.com/amoungui/lesson-02.git

2. Open library.slnx in Visual Studio.

3. Build with Ctrl+Shift+B.

4. Run with F5.

## Expected output
========================================
   Welcome to the library
========================================
Manage books, members and loans.
========================================
