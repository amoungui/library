# Lesson 04 — Arithmetic operators

Fourth lesson of the capstone project **Library**. The program manages the
stock of books by simulating a loan and a restocking operation.

## Learning objectives

- Use arithmetic operators (`--` and `+=`)
- Modify the value of an existing variable
- Understand the difference between a decrement and an addition
- Apply these concepts to the library stock management project

## Build and run

1. Clone the repository or download the ZIP:
   ```bash
   git clone https://github.com/amoungui/lesson-04.git

2. Open library.slnx in Visual Studio.

3. Build with Ctrl+Shift+B.

4. Run with F5.

## Expected output

Apres reapprovisionnement, stock final : 14
